# Pronunciation list

Text-to-speech falls over on exactly the words this show is made of. The
`.voice.txt` file for each edition is already respelled using this list — this
is the record of what was changed and why, so the next edition can be respelled
the same way in about a minute.

**These are starting guesses.** They were written without hearing the output.
Listen to the first generation, fix what is wrong, and correct the row here so
the mistake is made once. The list is the asset; after a month it does most of
the work, because the same fifty names recur.

## Rules that apply every time

- **Spell numbers out.** `1983` becomes `nineteen eighty-three`, `1947` becomes
  `nineteen forty-seven`, `2` in a film title becomes `Two`. Left as digits, the
  read is a coin flip.
- **Initialisms get full stops and spaces.** `TVF` becomes `T. V. F.`, or it is
  read as a word.
- **Crore stays "crore".** It has come out right so far. If it does not, try
  `kror`.
- **Drop the quotation marks around a quote** and lead into it with a comma —
  `his own phrase for it was, like life coming full circle`. Read marks aloud
  and TTS puts an odd pause where the punctuation is.
- **Em dashes are fine** and give a usable beat. Semicolons are not; split the
  sentence instead.
